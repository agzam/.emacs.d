Non-negotiable constraints (hard-won, spec's Verified findings):
- Live working environments: browser and Emacs session are not test
  harnesses. Probes non-destructive, own scratch players/tabs only,
  near-silent player volume - never tab mute (MPRIS invisibility),
  unwind-protect all session state, elisp-eval hygiene per AGENTS.
- One ECA session at a time on this Emacs: a parallel session once
  raced the edit tool into file corruption (spec Progress caveat).
  After any edit anomaly, diff the whole file before trusting it.
- Keysend facts: Chromium discards unfocused synthetic keys - the
  batched hyprctl focus-bounce is the delivery; injected keys land
  in the active tab like typing, so Vimium-C must exclude the site
  and the video tab must be frontmost; shifted keysyms need SHIFT
  specs; hyprctl says "ok" regardless - verify by eyes/effect.
- Naming: plain descriptive names - no +prefixes, no invented
  namespaces (AGENTS.md).
- Own packages declare plain GitHub recipes; local-dev-packages +
  local-checkout-recipe (init.el) redirect to ~/GitHub checkouts.
  NEVER commit a literal local :repo - CI smoke dies on it.
- Verification gates: bb lint, bb test (buttercup output is huge -
  always filter: bb test 2>&1 | rg "FAILED|Ran"), bb smoke, bb
