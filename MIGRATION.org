* Conventions debt
** DONE Rename sweep: drop Doom =+= prefixes
Done across the whole config (defs + refs, vendored tree included).
Rule for every future port: strip leading =+=, =+module/fn= becomes
=module-fn=; check the target name against the live session for collisions
before settling. Sources in ~/.doom.d still carry =+= names - rename on copy
to match references already renamed here. Non-mechanical mappings already
committed to:
- =+default/yank-pop= -> =yank-pop+=, =+default/dired= -> =dired-prompt=,
  =+default--search-dir= -> =search-in-dir=, =+default/*= -> bare names
- =+eval/buffer= -> =eval-buffer+= (real =eval-buffer= exists)
- =+evil{/,-}window-move-*= -> =window-move-*=
- =+multiple-cursors/evil-mc-*= -> =mc-*=
- =+vertico/switch-workspace-buffer= -> =switch-workspace-buffer=
- =+default/lsp-command-map= -> real =lsp-command-map=,
  =+default/insert-file-path= -> their =insert-file-path= (deliberate merges)
- =doom/delete-backward-word= -> =delete-backward-word=
- module flags (=+icons=, =+everywhere=, ...) are modulep! syntax - keep

* Official Doom modules: port or drop
Each needs a lab decision; bindings tree + registry already assume them.
- :emacs undo -> covered by infra undo item
- :config default +smartparens -> covered by infra item
- :tools lookup :: set-lookup-handlers! infra, +lookup-provider-url-alist,
  K/gd muscle memory. Needed by completion (consult-dash), golang, lua,
  clojure. Decide: vendor Doom lookup module vs thin own implementation.
- :tools eval +overlay :: set-repl-handler!/set-eval-handler! + eros overlays.
  Needed by golang/nix REPL handlers.
- :tools lsp +peek :: fold into custom lsp module port.
- :editor multiple-cursors :: evil-mc + evil-multiedit (evil-multiedit
  referenced by evil-escape excluded-states already).
- :editor file-templates :: yasnippet templates infra; elisp module ships own.
- :ui window-select :: ace-window (SPC w W/M/D bindings reference it).
- :ui zen :: writeroom-mode (+ config.el writeroom guards already ported).
- :ui vi-tilde-fringe :: cosmetic, trivial.
- :emacs vc :: git-timemachine, smerge hydra; fold into git module port.
- :emacs ibuffer :: groups/icons; general module has own ibuffer config -
  maybe drop Doom's.
- :emacs electric, tramp :: small defaults; likely inline into config.el.
- :term eshell :: aliases/prompt; fold into shell module port.
- :checkers syntax +childframe :: flycheck + posframe; their config disables
  global-flycheck - decide scope.
- :checkers grammar :: langtool/writegood; likely drop (writing module covers).
- :os macos :: open-with commands, env fixes (their osx module + macos deps).
- :lang emacs-lisp/json/markdown/sh :: port with respective language work;
  markdown +grip referenced by writing autoloads.
